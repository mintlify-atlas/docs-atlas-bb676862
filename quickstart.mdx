# Quick start

This guide will walk you through creating your first program with Kass. We'll explore task inspection, thread enumeration, and host information queries.

## Prerequisites

Make sure you've completed the [installation](/installation) steps and added Kass to your Swift package.

## Your first Kass program

Let's create a simple program that inspects the current task and prints information about it.

<Steps>
  <Step title="Create a new Swift file">
    Create a file named `main.swift` in your project:

    ```swift main.swift
    import MachCore
    ```
  </Step>

  <Step title="Get the current task">
    Access the current task and retrieve its basic information:

    ```swift main.swift
    import MachCore

    // Get the current task
    let currentTask = Mach.Task.current

    // Get the process ID
    let pid = try currentTask.pid
    print("Current task PID: \(pid)")
    ```

    <Note>
      `Mach.Task.current` provides a reference to the current process's task port. This is the primary way to interact with your own process through the Mach interface.
    </Note>
  </Step>

  <Step title="Retrieve task information">
    Query detailed information about the task:

    ```swift main.swift
    import MachCore

    let currentTask = Mach.Task.current
    let pid = try currentTask.pid
    print("Current task PID: \(pid)")

    // Get basic task information
    let basicInfo = try currentTask.info.basicInfo
    print("Virtual memory size: \(basicInfo.virtual_size) bytes")
    print("Resident memory size: \(basicInfo.resident_size) bytes")
    print("Suspend count: \(basicInfo.suspend_count)")
    ```

    The `info` property provides a `TaskInfoManager` that exposes various information flavors about the task.
  </Step>

  <Step title="Enumerate threads">
    List all threads in the current task:

    ```swift main.swift
    import MachCore

    let currentTask = Mach.Task.current
    let pid = try currentTask.pid
    print("Current task PID: \(pid)")

    let basicInfo = try currentTask.info.basicInfo
    print("Virtual memory size: \(basicInfo.virtual_size) bytes")
    print("Resident memory size: \(basicInfo.resident_size) bytes")

    // Get all threads in the task
    let threads = try currentTask.threads
    print("\nNumber of threads: \(threads.count)")
    
    for (index, thread) in threads.enumerated() {
        print("Thread \(index): \(thread.name)")
    }
    ```

    <Tip>
      The `threads` property returns an array of `Mach.Thread` objects representing all threads in the task.
    </Tip>
  </Step>

  <Step title="Run your program">
    Build and run your program:

    ```bash
    swift run
    ```

    You should see output similar to:

    ```
    Current task PID: 12345
    Virtual memory size: 4294967296 bytes
    Resident memory size: 16777216 bytes

    Number of threads: 4
    Thread 0: 0x00001234
    Thread 1: 0x00005678
    Thread 2: 0x00009abc
    Thread 3: 0x0000def0
    ```
  </Step>
</Steps>

## Complete example

Here's the complete program with error handling:

```swift main.swift
import MachCore
import Foundation

do {
    // Get the current task
    let currentTask = Mach.Task.current
    let pid = try currentTask.pid
    print("Current task PID: \(pid)")
    
    // Get basic task information
    let basicInfo = try currentTask.info.basicInfo
    print("Virtual memory size: \(basicInfo.virtual_size) bytes")
    print("Resident memory size: \(basicInfo.resident_size) bytes")
    print("Suspend count: \(basicInfo.suspend_count)")
    
    // Get memory information
    let vmInfo = try currentTask.info.vmInfo
    print("\nVirtual memory info:")
    print("  Page size: \(vmInfo.page_size) bytes")
    print("  Phys footprint: \(vmInfo.phys_footprint) bytes")
    
    // Enumerate threads
    let threads = try currentTask.threads
    print("\nNumber of threads: \(threads.count)")
    
    for (index, thread) in threads.enumerated() {
        print("Thread \(index): \(String(format: "0x%08x", thread.name))")
    }
    
} catch {
    print("Error: \(error)")
}
```

## Exploring host information

You can also query information about the host system:

```swift
import MachCore

let host = Mach.Host.current

// Get kernel version
let kernelVersion = try host.kernelVersion
print("Kernel version: \(kernelVersion)")

// Get page size
let pageSize = try host.pageSize
print("Page size: \(pageSize) bytes")

// Get basic host information
let hostInfo = try host.info.basic
print("CPU type: \(hostInfo.cpu_type)")
print("CPU subtype: \(hostInfo.cpu_subtype)")
print("Physical CPUs: \(hostInfo.physical_cpu)")
print("Logical CPUs: \(hostInfo.logical_cpu)")
print("Memory size: \(hostInfo.max_mem) bytes")
```

## Working with other tasks

To inspect other processes, you need their task port. This typically requires elevated privileges:

<Warning>
  Accessing task ports of other processes requires appropriate entitlements and/or running with elevated privileges. This is restricted by macOS security policies.
</Warning>

```swift
import MachCore

// Get task for a specific PID (requires privileges)
do {
    let targetPID: pid_t = 1234
    let targetTask = try Mach.Task.forPID(targetPID)
    
    let basicInfo = try targetTask.info.basicInfo
    print("Target task virtual size: \(basicInfo.virtual_size)")
    
} catch {
    print("Failed to get task for PID: \(error)")
}
```

## Common patterns

### Task suspension and resumption

```swift
import MachCore

let task = Mach.Task.current

// Suspend the task
try task.suspend()

// ... perform operations while suspended ...

// Resume the task
try task.resume()
```

### Thread control

```swift
import MachCore

let currentThread = Mach.Thread.current

// Suspend a thread
try currentThread.suspend()

// Resume a thread
try currentThread.resume()
```

### Port rights inspection

```swift
import MachCore

let task = Mach.Task.current
let ports = try task.ports

print("Task has \(ports.count) port names")

for port in ports.prefix(10) {
    let rights = try? port.rights
    print("Port \(String(format: "0x%08x", port.name)): \(rights?.rights ?? [])")
}
```

## Error handling

Kass functions that interact with the kernel throw errors of type `MachError`:

```swift
import MachCore

do {
    let info = try Mach.Task.current.info.basicInfo
    print("Success: \(info)")
} catch let error as MachError {
    switch error {
    case .invalidArgument:
        print("Invalid argument passed to kernel")
    case .failure:
        print("Kernel operation failed")
    default:
        print("Mach error: \(error)")
    }
} catch {
    print("Unexpected error: \(error)")
}
```
