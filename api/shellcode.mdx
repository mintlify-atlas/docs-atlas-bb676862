The Shellcode module provides tools for generating ARM64 machine code and injecting it into Mach tasks.

## Protocols

### ShellcodeRepresentable

A protocol for types that can be represented as raw shellcode bytes.

```swift
public protocol ShellcodeRepresentable {
    var shellcode: [UInt8] { get }
}
```

<ParamField path="shellcode" type="[UInt8]">
  The raw shellcode bytes
</ParamField>

---

## Task Injection

Extends `Mach.Task` with shellcode injection capabilities.

### inject(shellcode:stackSize:intoThread:withInitialState:)

Injects shellcode into a target task, either into an existing thread or by creating a new bare Mach thread.

```swift
public func inject(
    shellcode: [UInt8],
    stackSize: mach_vm_size_t = 1024 * 1024,
    intoThread thread: Mach.Thread? = nil,
    withInitialState initialState: Mach.ThreadState<some BitwiseCopyable> = .none
) throws -> (
    shellcodePointer: UnsafeRawPointer?,
    stackPointer: UnsafeRawPointer?,
    thread: Mach.Thread?
)
```

<ParamField path="shellcode" type="[UInt8]">
  The shellcode bytes to inject
</ParamField>

<ParamField path="stackSize" type="mach_vm_size_t" default="1024 * 1024">
  Size of the stack to allocate (default: 1MB)
</ParamField>

<ParamField path="thread" type="Mach.Thread?" default="nil">
  Existing thread to inject into, or `nil` to create a new thread
</ParamField>

<ParamField path="initialState" type="Mach.ThreadState<some BitwiseCopyable>" default=".none">
  Initial thread state to set before execution
</ParamField>

<ResponseField name="Returns" type="tuple">
  A tuple containing:
  - `shellcodePointer`: Pointer to the injected shellcode in the target task
  - `stackPointer`: Pointer to the allocated stack
  - `thread`: The thread that will execute the shellcode
</ResponseField>

<Warning>
  - A bare Mach thread cannot do much without an associated POSIX thread. It is up to the caller to create and associate a POSIX thread.
  - Injecting into a running thread may cause unexpected behavior.
  - This currently only supports ARM64 architecture.
</Warning>

#### Example

```swift
import Shellcode
import MachCore

// Create shellcode (ARM64 NOP instruction)
let shellcode: [UInt8] = [
    0x1F, 0x20, 0x03, 0xD5  // NOP
]

// Get target task
let task = try Mach.Task.forPID(1234)

// Inject shellcode into a new thread
let (codePtr, stackPtr, thread) = try task.inject(
    shellcode: shellcode,
    stackSize: 2 * 1024 * 1024
)

print("Shellcode injected at: \(codePtr!)")
print("Stack allocated at: \(stackPtr!)")
print("Thread: \(thread!)")

// Resume the thread to execute shellcode
try thread?.resume()
```

## A64 Instruction Set

The module includes a comprehensive ARM64 instruction encoder.

### A64InstructionSet

```swift
public struct A64InstructionSet: InstructionSet {
    public struct Instruction: Shellcode.Instruction {
        public typealias EncodedForm = UInt32
        public var rawValue: [UInt8]
    }
}
```

### Complete Example

```swift
import Shellcode
import MachCore

// Build ARM64 shellcode using instruction encoder
let instructions: [A64InstructionSet.Instruction] = [
    .MOVZ(Xd: 0, imm: 42, shift: 0),      // X0 = 42
    .ADD(Xd: 0, Xn: 0, imm: 8, shift: false),  // X0 += 8
    .BR(Xn: 30)                            // Return
]

// Convert to raw bytes
let shellcode = instructions.shellcode

// Inject into task
let task = try Mach.Task.forPID(1234)
let result = try task.inject(shellcode: shellcode)

print("Injected \(shellcode.count) bytes at \(result.shellcodePointer!)")
```

  The A64 instruction set implementation is based on the ARM Architecture Reference Manual (ARM DDI 0487).
