## Overview

The BSDCore Process API provides comprehensive access to process information through the `proc_info` family of system calls. You can query process details, list PIDs, get file descriptor information, and more.

## Proc Structure

Represents a process with a specific PID.

```swift

```

## Example Usage

<CodeGroup>

```swift Get Process Info
import BSDCore

let proc = BSD.Proc(pid: 1234)

// Get the executable path
if let path = try proc.path {
    print("Process path: \(path)")
}

// Get BSD info
let bsdInfo = try proc.bsdInfo
print("Process name: \(String(cString: &bsdInfo.pbi_name))")

// Get task info
let taskInfo = try proc.taskInfo
print("Virtual size: \(taskInfo.pti_virtual_size)")
print("Resident size: \(taskInfo.pti_resident_size)")
```

```swift List All PIDs
import BSDCore

// List all PIDs in the system
let allPIDs = try BSD.Proc.listPIDs(
    BSD.ProcPIDListDescription(type: .all)
)

print("Total processes: \(allPIDs.count)")
for pid in allPIDs {
    print("PID: \(pid)")
}
```

```swift List PIDs by User
import BSDCore

// List PIDs for a specific user (UID 501)
let userPIDs = try BSD.Proc.listPIDs(
    BSD.ProcPIDListDescription(
        type: .uidOnly,
        info: 501
    )
)

print("Processes for UID 501: \(userPIDs.count)")
```

```swift Get File Descriptors
import BSDCore

let proc = BSD.Proc(pid: getpid())

// Get all file descriptors
let fds = try proc.fileDescriptors

for fd in fds {
    print("FD: \(fd.proc_fd)")
    print("Type: \(fd.proc_fdtype)")
}
```

```swift Get Thread Information
import BSDCore

let proc = BSD.Proc(pid: getpid())

// Get thread IDs
let threadIDs = try proc.threadIDs
print("Thread count: \(threadIDs.count)")

for threadID in threadIDs {
    let info = try proc.threadInfo(threadID: threadID)
    print("Thread \(threadID): \(info.pth_user_time) user time")
}
```

```swift Get Architecture Info
import BSDCore

let proc = BSD.Proc(pid: 1234)
let archInfo = try proc.archInfo

print("CPU type: \(archInfo.p_cputype)")
print("CPU subtype: \(archInfo.p_cpusubtype)")
```

</CodeGroup>

## Kernel Message Buffer

```swift
public static func getKernelMessageBuffer(
    largeBuffer: Bool = true
) throws -> Data
```

<ParamField path="largeBuffer" type="Bool">
  Whether to use a large buffer (131072 bytes) or small (16384 bytes). Default is true.
</ParamField>

Gets the kernel message buffer. This must be called with root privileges.

```swift
import BSDCore

// Get kernel messages (requires root)
let messages = try BSD.Proc.getKernelMessageBuffer()
if let messageString = String(data: messages, encoding: .utf8) {
    print(messageString)
}
```

## Notes

- Most operations require appropriate privileges
- Many properties throw errors if the process doesn't exist or access is denied
- Thread addresses are pointers to thread-specific data structures
- The `proc_info` call is more efficient than multiple individual queries
