## Overview

The BSDCore Code Signing API provides access to macOS code signing operations through the `csops` family of system calls. You can query and manipulate code signing attributes, retrieve entitlements, and validate processes.

## CSOps Methods

### call

Performs a code signing operation on a process.

```swift
public static func call(
    forPID pid: pid_t,
    _ ops: CSOperation,
    auditToken: audit_token_t? = nil,
    dataIn: Data = Data(),
    ignoreERANGE: Bool = false
) throws -> Data
```

<ParamField path="pid" type="pid_t" required>
  The process ID to operate on
</ParamField>

<ParamField path="ops" type="CSOperation" required>
  The operation to perform
</ParamField>

<ParamField path="auditToken" type="audit_token_t?">
  Optional audit token for the operation
</ParamField>

<ParamField path="dataIn" type="Data">
  Input data for the operation (default: empty)
</ParamField>

<ParamField path="ignoreERANGE" type="Bool">

## Example Usage

<CodeGroup>

```swift Get Code Signing Status
import BSDCore

let pid = getpid()
let flags = try BSD.CSOps.getStatus(forPID: pid)

if flags.contains(.valid) {
    print("Code signature is valid")
}

if flags.contains(.adhoc) {
    print("Binary is ad-hoc signed")
}

if flags.contains(.runtime) {
    print("Hardened runtime is enabled")
}

if flags.contains(.platformBinary) {
    print("This is a platform binary")
}
```

```swift Get Entitlements
import BSDCore

let pid: pid_t = 1234

// Get XML entitlements
let entitlementsData = try BSD.CSOps.getEntitlementsBlob(forPID: pid)
if let entitlementsXML = String(data: entitlementsData, encoding: .utf8) {
    print("Entitlements:\n\(entitlementsXML)")
}
```

```swift Get Signing Identity and Team
import BSDCore

let pid = getpid()

if let identity = try BSD.CSOps.getIdentity(forPID: pid) {
    print("Signing identity: \(identity)")
}

if let teamID = try BSD.CSOps.getTeamID(forPID: pid) {
    print("Team ID: \(teamID)")
}
```

```swift Get Validation Category
import BSDCore

let pid: pid_t = 1234
let category = try BSD.CSOps.getValidationCategory(forPID: pid)

switch category.rawValue {
case BSD.CSValidationCategory.appStore.rawValue:
    print("App Store app")
case BSD.CSValidationCategory.developerID.rawValue:
    print("Developer ID signed")
case BSD.CSValidationCategory.development.rawValue:
    print("Development signed")
case BSD.CSValidationCategory.platform.rawValue:
    print("Platform binary")
default:
    print("Other category")
}
```

```swift Get Code Directory Hash
import BSDCore

let pid = getpid()
let cdHash = try BSD.CSOps.getCDHash(forPID: pid)

print("CD Hash: \(cdHash.map { String(format: "%02x", $0) }.joined())")
```

```swift Check Multiple Processes
import BSDCore

let pids = try BSD.Proc.listPIDs(
    BSD.ProcPIDListDescription(type: .all)
)

for pid in pids {
    do {
        let flags = try BSD.CSOps.getStatus(forPID: pid)
        if flags.contains(.platformBinary) {
            if let identity = try? BSD.CSOps.getIdentity(forPID: pid) {
                print("PID \(pid): \(identity)")
            }
        }
    } catch {
        // Process may have exited or we lack permissions
        continue
    }
}
```

</CodeGroup>

## Notes

- Most operations require appropriate entitlements or elevated privileges
- The blob header is automatically stripped from blob operations
- When `ignoreERANGE` is true, the operation will still copy available data even if ERANGE is returned
- Audit tokens provide an alternative authentication mechanism
- Library validation flag clearing is restricted to the caller's own PID
