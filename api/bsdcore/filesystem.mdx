## Overview

The BSDCore Filesystem API provides powerful low-level access to file and directory attributes through the `getattrlist` system call. This API allows you to efficiently retrieve multiple file attributes in a single system call.

## Getting Attributes

Use the `attrlist` extension to retrieve file attributes.

### Method

```swift
public func get(
    for path: String,
    options: BSD.FSOptions
) throws -> BSD.FSAttributeBuffer
```

<ParamField path="path" type="String" required>
  The path to the file or directory
</ParamField>

<ParamField path="options" type="BSD.FSOptions" required>
  Options for the operation
</ParamField>

### Example Usage

<CodeGroup>

```swift Basic Attributes
import BSDCore

// Create an attribute list
var attrList = attrlist(
    commonAttributes: [.name, .modificationTime, .creationTime],
    fileAttributes: [.logicalSize, .physicalSize]
)

// Get attributes for a file
let buffer = try attrList.get(
    for: "/path/to/file.txt",
    options: []
)

// Parse the buffer to access attributes
```

```swift Volume Attributes
import BSDCore

// Get volume information
var attrList = attrlist(
    volumeAttributes: [
        .size,
        .freeSpace,
        .availableSpace,
        .name,
        .mountPoint
    ]
)

let buffer = try attrList.get(
    for: "/",
    options: []
)
```

```swift Extended Attributes
import BSDCore

// Get extended attributes
var attrList = attrlist(
    commonAttributes: [.name, .fileID],
    commonExtendedAttributes: [.cloneID, .realDeviceID]
)

let buffer = try attrList.get(
    for: "/path/to/file",
    options: .useExtendedCommonAttributes
)
```

```swift No Follow Symlinks
import BSDCore

// Get attributes without following symlinks
var attrList = attrlist(
    commonAttributes: [.name, .objectType]
)

let buffer = try attrList.get(
    for: "/path/to/symlink",
    options: .noFollow
)
```

</CodeGroup>

## Notes

- The `getattrlist` system call is more efficient than multiple `stat` calls when you need multiple attributes
- Use `FSOptions.noFollow` to get information about symbolic links themselves rather than their targets
- Extended common attributes require the `useExtendedCommonAttributes` option
- The attribute buffer must be parsed according to the requested attributes in order
