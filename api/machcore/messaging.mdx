# Messaging API

The Messaging API provides Swift-friendly access to Mach messages, which are the foundation of inter-process communication (IPC) in Mach.

## Message Body

### Mach.MessageBody

The message body contains descriptors for complex messages.

```swift
public class MessageBody
```

Message bodies are used when sending port rights, out-of-line memory, or other complex data in messages.

## Message Descriptors

Message descriptors are used to send complex data types in messages. The available descriptor types depend on what you're sending (ports, memory regions, etc.).

## Usage Example

```swift
import Mach
import Foundation

// Create a simple message
let message = Mach.Message(
    descriptors: nil,
    payload: "Hello, Mach!".data(using: .utf8)
)

// Get a send port (e.g., from bootstrap)
let task = Mach.Task.current
let sendPort = try task.getSpecialPort(.bootstrap, as: Mach.Port.self)

// Configure the message header
message.header.msgh_remote_port = sendPort.name
message.header.msgh_local_port = MACH_PORT_NULL
message.header.msgh_bits = mach_msg_bits_t(
    MACH_MSG_TYPE_COPY_SEND,
    0,
    0
)

// Send the message
try Mach.Message.send(
    message,
    to: sendPort,
    options: [],
    timeout: 1000
)

// Receive a message from a port
let receivePort = try Mach.Port(named: /* some port name */)  
let receivedMessage = try Mach.Message.receive(
    Mach.Message.self,
    from: receivePort,
    timeout: 5000
)

// Access the received data
if let payload = receivedMessage.payload {
    let string = String(data: payload, encoding: .utf8)
    print("Received: \(string ?? "<invalid>"")
}

// Send and receive in one operation
let replyMessage = try Mach.Message.send(
    message,
    to: sendPort,
    receiving: Mach.Message.self,
    from: receivePort,
    timeout: 5000
)

// Work with message header
print("Message size: \(receivedMessage.header.msgh_size)")
print("Message ID: \(receivedMessage.header.msgh_id)")
print("Remote port: \(String(format: "0x%x", receivedMessage.header.msgh_remote_port))")
```

## Advanced Usage

### Serialization

```swift
// Manually serialize a message
let message = Mach.Message()
message.withUnsafeSerializedMessage { headerPointer in
    // Use the serialized message buffer
    // Be careful: the buffer is deallocated when the closure returns
}

// Or get a pointer and manage it yourself
let headerPointer = message.serialize()
defer { headerPointer.deallocate() }

// Use the pointer for low-level operations
try Mach.Message.message(
    headerPointer,
    options: [.send],
    sendSize: mach_msg_size_t(message.header.msgh_size),
    receiveSize: 0,
    receivePort: .Nil
)
```

### Deserialization

```swift
// Deserialize from a buffer
let buffer: UnsafeMutablePointer<mach_msg_header_t> = // ... from somewhere
let deserializedMessage = Mach.Message(headerPointer: buffer)

// Now you can access all message components
print("Payload size: \(deserializedMessage.payload?.count ?? 0)")
```
