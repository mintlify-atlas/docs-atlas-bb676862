# Thread API

The Thread API provides Swift-friendly access to Mach threads, which are the unit of CPU execution within tasks.

## Core Types

### Mach.Thread

A thread in a task.

```swift
public class Thread: Mach.Port
```

#### Static Properties

<ResponseField name="current" type="Mach.ThreadControl">
  The current thread
  
  ```swift
  public static var current: Mach.ThreadControl
  ```
</ResponseField>

#### Initializers

```swift
public convenience init(inTask task: Task) throws
```

Creates a new thread in a given task.

**Warning:** The initial execution state of the thread is undefined. Use `init(inTask:runningWithState:)` to create a thread with a defined initial state.

---

```swift
public convenience init<DataType>(
    inTask task: Task,
    runningWithState state: ThreadState<DataType>
) throws where DataType: BitwiseCopyable
```

Creates a new running thread in a given task with a given state.

#### Instance Properties

<ResponseField name="info" type="Mach.ThreadInfoManager">
  The thread's info manager
  
  ```swift
  public var info: Mach.ThreadInfoManager
  ```
</ResponseField>

<ResponseField name="tsdAddress" type="UnsafeMutableRawPointer?">
  The address of the thread-specific data (TSD) for the thread
  
  ```swift
  public var tsdAddress: UnsafeMutableRawPointer?
  ```
</ResponseField>

#### Methods

```swift
public func suspend() throws
```

Suspends the thread.

---

```swift
public func resume() throws
```

Resumes the thread.

---

```swift
public func abort(safely: Bool = true) throws
```

Aborts the thread.

<ParamField path="safely" type="Bool" default="true">
  Whether to abort safely
</ParamField>

---

```swift
public func terminate() throws
```

Terminates the thread.

---

```swift
public func wire(in host: Mach.Host = .current) throws
```

Wires a thread to prevent it from being paged out.

---

```swift
public func unwire(in host: Mach.Host = .current) throws
```

Unwires a thread.

---

```swift
public static func switch(
    to thread: Mach.Thread,
    option: Mach.ThreadSwitchOption = .none,
    timeout: mach_msg_timeout_t
) throws
```

Switches to a thread.

---

```swift
public func abortDepression() throws
```

Aborts the depression of the thread.

**Note:** A thread may be in a depressed state due to a thread switching call.

---

```swift
public func getState<DataType>(_ state: Mach.ThreadState<DataType>) throws -> DataType
```

Gets state for the thread.

**Warning:** This call will fail if data is included in the state argument.

---

```swift
public func setState<DataType>(_ state: Mach.ThreadState<DataType>) throws
```

Sets state for the thread.

**Warning:** This call will fail if data is not included in the state argument.

## Usage Example

```swift
import Mach

// Get the current thread
let thread = Mach.Thread.current

// Get basic info
let basicInfo = try thread.info.basicInfo
print("User time: \(basicInfo.user_time)")
print("System time: \(basicInfo.system_time)")
print("Run state: \(basicInfo.runState)")

// Get identifier info
let identifierInfo = try thread.info.identifyingInfo
print("Thread ID: \(identifierInfo.thread_id)")

// Suspend and resume
try thread.suspend()
defer { try? thread.resume() }

// Create a new thread in the current task
let task = Mach.Task.current
let newThread = try Mach.Thread(inTask: task)
defer { try? newThread.terminate() }

// Work with thread state (ARM64 example)
#if arch(arm64)
let state = try newThread.getState(.arm64)
print("PC: \(state.__pc)")
print("SP: \(state.__sp)")

// Modify and set state
var modifiedState = state
modifiedState.__pc = 0x1000  // Set program counter
try newThread.setState(.arm64(modifiedState))
#endif

// Get all threads in a task
let threads = try task.threads
for (index, t) in threads.enumerated() {
    let info = try t.info.basicInfo
    print("Thread \(index): \(info.runState)")
}

// Switch to a thread
try Mach.Thread.switch(
    to: threads.first!,
    option: .none,
    timeout: 1000
)
```
