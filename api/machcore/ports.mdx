# Port API

The Port API provides Swift-friendly access to Mach ports, which are the fundamental IPC primitive in the Mach kernel.

## Core Types

### Mach.Port

A port name in a task's name space.

```swift
open class Port
```

<ParamField path="name" type="mach_port_name_t">
  The name of the port in the owning task's name space
</ParamField>

<ParamField path="owningTask" type="Mach.Task">
  The task that the port name is in the name space of
</ParamField>

#### Initializers

```swift
public required init(named name: mach_port_name_t, inNameSpaceOf task: Task = .current)
```

References an existing port.

<ParamField path="name" type="mach_port_name_t" required>
  The port name in the task's name space
</ParamField>

<ParamField path="task" type="Task" default=".current">
  The task whose name space contains the port
</ParamField>

#### Properties

<ResponseField name="rights" type="Mach.PortRights">
  The port rights named by this port (throws on failure)
  
  ```swift
  public var rights: Mach.PortRights { get throws }
  ```
</ResponseField>

<ResponseField name="kernelObject" type="Mach.KernelObject">
  The kernel object underlying the port (throws on failure)
  
  ```swift
  public var kernelObject: Mach.KernelObject { get throws }
  ```
</ResponseField>

<ResponseField name="context" type="mach_port_context_t">
  The context of the port (throws on failure)
  
  ```swift
  public var context: mach_port_context_t { get throws }
  ```
</ResponseField>

<ResponseField name="sendRightCount" type="Int">
  The number of send rights the receive right has (throws on failure)
  
  **Important:** This port name must name a receive right.
  
  ```swift
  public var sendRightCount: Int { get throws }
  ```
</ResponseField>

<ResponseField name="guarded" type="Bool">
  Whether the port is guarded (experimental)
  
  **Warning:** This property being `false` doesn't mean that the port was determined to not be guarded. Instead, it means that it was not determined to be guarded. However, it being `true` means that the port was determined to be guarded.
  
  ```swift
  public var guarded: Bool
  ```
</ResponseField>

<ResponseField name="attributes" type="Mach.PortAttributeManager">
  The attributes of the port
  
  ```swift
  public var attributes: Mach.PortAttributeManager
  ```
</ResponseField>

#### Methods

```swift
public func getContext() throws -> mach_port_context_t
```

Gets the context of the port.

---

```swift
public func setContext(to context: mach_port_context_t) throws
```

Sets the context of the port.

---

```swift
public func setMakeSendCount(to count: Int32) throws
```

Sets the make-send count of the port.

---

```swift
public func guard(with context: mach_port_context_t, flags: Mach.PortGuardFlags = []) throws
```

Guards the port using the specified context and flags.

<ParamField path="context" type="mach_port_context_t" required>
  The guard context value
</ParamField>

<ParamField path="flags" type="Mach.PortGuardFlags" default="[]">
  Guard flags (e.g., `.strict`, `.immovableReceive`)
</ParamField>

---

```swift
public func unguard(with context: mach_port_context_t) throws
```

Unguards the port using the specified context.

---

```swift
public func extractRight<PortType: Mach.Port>(
    using disposition: Mach.PortDisposition,
    intoNameSpaceOf receivingTask: Mach.Task = .current
) throws -> PortType
```

Extracts a right from the port and brings it into a given task's name space.

---

```swift
public func insertRight(
    intoNameSpaceOf task: Mach.Task,
    using disposition: Mach.PortDisposition
) throws
```

Inserts a right from the port into the specified task's name space.

---

```swift
public func move(to set: Mach.PortSet) throws
```

Moves the port into a port set.

**Warning:** If the port is already a member of any other port sets, it will be removed from them.

---

```swift
public func insert(into set: Mach.PortSet) throws
```

Inserts the port into a port set.

---

```swift
@available(macOS, deprecated: 12.0)
open func destroy() throws
```

Destroys the port.

**Warning:** This is an inherently unsafe API. Instead manage rights with `destruct(guard:sendRightDelta:)`, `deallocate()` or `userRefs(for:)`.

## Usage Example

```swift
import Mach

// Get a port from the current task
let task = Mach.Task.current
let ports = try task.ports

for port in ports {
    // Get port rights
    let rights = try port.rights
    print("Port \(port.name) has rights: \(rights)")
    
    // Get kernel object info
    let kernelObj = try port.kernelObject
    print("Kernel object type: \(kernelObj.type)")
    
    // Check if port is guarded
    if port.guarded {
        print("Port is guarded")
    }
}

// Work with port attributes
let port = ports.first!
let limits = try port.attributes.limits
print("Queue limit: \(limits.mpl_qlimit)")

// Guard a port
let guardContext: mach_port_context_t = 0x1234567890ABCDEF
try port.guard(with: guardContext, flags: [.strict])
defer { try? port.unguard(with: guardContext) }
```
