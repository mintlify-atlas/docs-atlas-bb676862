# Exception API

The Exception API provides Swift-friendly access to Mach exception handling, which allows applications to intercept and handle hardware and software exceptions.

## Core Types

### Mach.ExceptionPort

An exception port.

```swift
public class ExceptionPort: Mach.Port
```

<ResponseField name="mask" type="Mach.ExceptionMask">
  The mask of the exception types that the port will catch
</ResponseField>

<ResponseField name="behavior" type="Mach.ExceptionBehavior">
  The behavior of the exception
</ResponseField>

<ResponseField name="threadStateFlavor" type="thread_state_flavor_t">
  The flavor of the thread state to send with exception messages
</ResponseField>

#### Initializer

```swift
public init(
    named name: mach_port_name_t,
    mask: Mach.ExceptionMask = .all,
    behavior: Mach.ExceptionBehavior = .default,
    threadStateFlavor: Mach.ThreadState<some BitwiseCopyable> = .none

```

Creates an exception port.

<ParamField path="name" type="mach_port_name_t" required>

</ParamField>

<ParamField path="mask" type="Mach.ExceptionMask" default=".all">
  The exception mask
</ParamField>

<ParamField path="behavior" type="Mach.ExceptionBehavior" default=".default">
  The exception behavior
</ParamField>

<ParamField path="threadStateFlavor" type="Mach.ThreadState" default=".none">
  The thread state flavor
</ParamField>

#### Methods

```swift

    _ type: Mach.ExceptionType,
    code: Int32,
    subcode: Int32,
    inThread thread: Mach.Thread = Mach.Thread.current,
    inTask task: Mach.Task = Mach.Task.current,
    wasMaybePACFail: Bool = false
) throws
```

Raises an exception.

<ParamField path="type" type="Mach.ExceptionType" required>
  The type of exception to raise
</ParamField>

<ParamField path="code" type="Int32" required>

</ParamField>

<ParamField path="subcode" type="Int32" required>
  Exception subcode
</ParamField>

<ParamField path="thread" type="Mach.Thread" default="Mach.Thread.current">

</ParamField>

<ParamField path="task" type="Mach.Task" default="Mach.Task.current">

## Port with Exception Ports Protocol

### Mach.PortWithExceptionPorts

A protocol for ports that can have exception ports.

```swift
public protocol PortWithExceptionPorts: Mach.Port
```

Implemented by:
- `Mach.Task`
- `Mach.Thread`
- `Mach.Host`

#### Required Methods

```swift
func exceptionPorts(mask: Mach.ExceptionMask) throws -> [Mach.ExceptionPort]
```

Returns the exception ports for the port's kernel object for the types specified by the mask.

---

```swift
var exceptionPorts: [Mach.ExceptionPort] { get throws }
```

All the exception ports for the port's kernel object.

---

```swift
func addExceptionPort(_ exceptionPort: Mach.ExceptionPort) throws
```

Adds an exception port to the port's kernel object.

### Task Exception Port Extensions

```swift
extension Mach.Task: Mach.PortWithExceptionPorts {
    public func swapExceptionPort(with exceptionPort: Mach.ExceptionPort)
        throws -> [Mach.ExceptionPort]
}
```

Swaps an exception port for the task and returns the previous exception ports.

---

```swift
@available(macOS, introduced: 15.0)
public func registerHardenedExceptionHandler(
    _ exceptionPort: Mach.ExceptionPort,
    signedPCKey: UInt32
) throws
```

Registers a hardened exception handler for the task (macOS 15+).

## Usage Example

```swift
import Mach

// Get the current task
let task = Mach.Task.current

// Get all current exception ports
let currentPorts = try task.exceptionPorts
print("Current exception ports: \(currentPorts.count)")

for port in currentPorts {
    print("  Mask: \(port.mask)")
    print("  Behavior: \(port.behavior)")
    print("  Thread state flavor: \(port.threadStateFlavor)")
}

// Create a new exception port
let exceptionPort = Mach.ExceptionPort(
    named: /* your port name */,
    mask: [.badAccess, .badInstruction],
    behavior: .default,
    threadStateFlavor: .none
)

// Add the exception port to the current task
try task.addExceptionPort(exceptionPort)

// Query exception ports for specific exception types
let crashPorts = try task.exceptionPorts(mask: [.crash, .badAccess])
print("Ports handling crash and bad access: \(crashPorts.count)")

// Swap exception ports (returns old ports)
let oldPorts = try task.swapExceptionPort(with: exceptionPort)
print("Replaced \(oldPorts.count) old exception ports")

// Exception port on a thread
let thread = Mach.Thread.current
try thread.addExceptionPort(exceptionPort)

// Raise an exception (for testing)
try exceptionPort.raise(
    .software,
    code: 1,
    subcode: 0,
    inThread: thread,
    inTask: task
)
```

## Advanced Usage

### Handling Multiple Exception Types

```swift
// Create a mask for multiple exception types
let mask: Mach.ExceptionMask = [
    .badAccess,
    .badInstruction,
    .arithmetic,
    .breakpoint
]

// Check what exceptions are in the mask
for individualMask in mask.masks {
    print("Handling: \(individualMask)")
}

// Create exception port for these types
let port = Mach.ExceptionPort(
    named: /* port name */,
    mask: mask,
    behavior: .stateIdentity,
    threadStateFlavor: .arm64  // or .x86_64 on Intel
)
```

### Exception Handling at Different Levels

```swift
// Host-level exception handling (catches all tasks)
let host = Mach.Host.current
try Mach.ExceptionPort.addExceptionPort(hostExceptionPort, toHost: host)

// Task-level exception handling (catches all threads in task)
let task = Mach.Task.current
try Mach.ExceptionPort.addExceptionPort(taskExceptionPort, toTask: task)

// Thread-level exception handling (catches only this thread)
let thread = Mach.Thread.current
try Mach.ExceptionPort.addExceptionPort(threadExceptionPort, toThread: thread)
```

### Exception Port Hierarchy

Exception ports form a hierarchy:
1. Thread exception ports are checked first
2. Then task exception ports
3. Finally host exception ports

The first matching exception port in this hierarchy handles the exception.
