## Overview

MachCore provides Swift wrappers for the Mach portion of the XNU kernel. This is the most stable and feature-complete module in Kass, offering access to tasks, threads, ports, virtual memory management, IPC messaging, and more.

<Note>
**Source Location**: `Sources/Mach/Core/`

**Dependencies**: KassHelpers, KassC, Linking
</Note>

## Core Components

### Mach Namespace

The main entry point for all Mach operations:

```swift Mach.swift:6-23
public struct Mach: KassHelpers.Namespace {
    /// Executes a function that returns a Mach error code and throws an error if it fails.
    public static func call(_ call: @autoclosure () -> kern_return_t) throws {
        let kr = call()
        guard kr == KERN_SUCCESS else {
            guard let typedCode = MachError.Code(rawValue: kr) else {
                throw NSError(domain: NSMachErrorDomain, code: Int(kr))
            }
            throw MachError(typedCode)
        }
    }
}
```

The `Mach.call()` function is used throughout the module to wrap kernel calls and convert return codes to Swift errors.

## Threads

### Mach.Thread

Represents a thread within a task:

<CodeGroup>
```swift Creating Threads
// Create a new thread (undefined state)
let thread = try Mach.Thread(inTask: task)

// Create a running thread with initial state
var state = arm_thread_state64_t()
state.__pc = 0x100000000
state.__sp = 0x200000000
let runningThread = try Mach.Thread(
    inTask: task,
    runningWithState: Mach.ThreadState.arm64(state)
)
```

```swift Thread Control
// Current thread
let currentThread = Mach.Thread.current

// Suspend and resume
try thread.suspend()
try thread.resume()

// Abort thread
try thread.abort(safely: true)

// Terminate thread
try thread.terminate()
```

```swift Thread Switching
// Switch to another thread
try Mach.Thread.switch(
    to: thread,
    option: .depress,
    timeout: 1000
)

// Abort depression
try thread.abortDepression()
```
</CodeGroup>

            MACH_MSG_TIMEOUT_NONE,

## Error Handling

MachCore uses `MachError` for all kernel errors:

```swift
do {
    try Mach.call(some_mach_function())
} catch MachError.invalidArgument {
    print("Invalid argument passed")
} catch MachError.noAccess {
    print("Permission denied")
} catch let error as MachError {
    print("Mach error: \(error.code)")
}
```

## Performance Considerations

<Warning>
- Mach calls are expensive kernel traps
- Batch operations when possible
- Cache port references
- Use virtual memory operations sparingly
- Consider memory alignment for better performance
</Warning>
