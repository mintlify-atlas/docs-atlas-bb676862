# Introduction to Kass

Kass is a collection of modules for reverse-engineering and security research on macOS, written in Swift. It provides a comprehensive Swift-native interface for interacting with the XNU kernel that underlies macOS.

<Note>
  While Kass may compile on older versions of macOS, it is only thoroughly tested on the latest version. The library is primarily designed for reverse-engineering and security research, not production applications.
</Note>

## MachCore

The MachCore module provides facilities for interacting with the Mach portion of the XNU kernel. This is the most mature module in Kass and should be considered the most stable.

**Key features:**
- Task management and inspection
- Thread control and state manipulation
- Port rights and IPC messaging
- Virtual memory operations
- Host information queries
- Processor and processor set management

## BSDCore

The BSDCore module provides facilities for interacting with the BSD portion of the XNU kernel. This module is actively being developed and may be subject to changes.

<Warning>
  BSDCore is a work-in-progress and should not be considered stable. API changes may occur in future versions.
</Warning>

## Linking

The Linking module provides a simple API to access symbols using the `dlopen` and `dlsym` functions internally. This module will likely be folded into BSDCore in a future release.

## OSCore

The OSCore module provides macOS-specific features and integrations including:
- IOKit device interaction
- System notification APIs
- OS variant detection

## Platform support

Kass supports the following platforms:
- **macOS**: 10.13 and later
- **iOS**: 12.0 and later (experimental)

<Tip>
  The library is primarily tested and designed for macOS. iOS support is experimental and may have limitations.
</Tip>

## Use cases

Kass is designed for:
- Security research and auditing
- Reverse engineering tasks
- Low-level system introspection
- Kernel interface experimentation
- Educational purposes
